# 🚀 Personal Portfolio – Full-Stack Developer

> A dynamic, full-stack portfolio built with **React** (frontend) and **NestJS** (backend).  
> Features a dark/light theme, admin dashboard, contact form with email notifications, and a fully customizable skills/projects section.

### Frontend
- **React + Vite** – fast, modern SPA
- **Dark / Light Mode** – persistent theme toggle with localStorage
- **Dynamic Content** – all text, projects, and skills editable via admin dashboard
- **Glass-morphism UI** – modern, professional design
- **Fully Responsive** – mobile, tablet, desktop

### Backend
- **NestJS** – modular, TypeScript-first API
- **PostgreSQL + TypeORM** – robust, relational database
- **JWT Authentication** – secure admin login
- **Email Notifications** – contact form sends messages via Nodemailer
- **RESTful API** – clean endpoints for frontend consumption

### Admin Dashboard
- **Hero** – update title, subtitle, availability
- **About** – edit bio, tags, education, experience
- **Skills** – add, edit, delete skills (with icons and levels)
- **Projects** – create, update, delete projects with features, tech, GitHub/demo links
- **Contact** – change email, phone, location, social links
